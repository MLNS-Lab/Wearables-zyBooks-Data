# File Contents
#### bvp_e4.csv
CSV file containing timestamped blood volume pulse (BVP) readings taken for each subject over the duration of the experiment using the Empatica E4 wearable sensor, with annotations to associate each reading with a particular type of task.

#### gsr_e4.csv
CSV file containing timestamped skin conductance, or galvanic skin response (GSR), readings taken for each subject over the duration of the experiment using the Empatica E4 wearable sensor, with annotations to associate each reading with a particular type of task.

#### activity_events.csv
CSV file containing timestamped click events generated by subjects interacting with zyBooks challenge activities. Each event is associated with an ID denoting the question set, a caption describing the question set, an integer denoting the question number within the set, a Boolean flag indicating whether the current question has been correctly answered, and a string denoting the type of click event.

#### animation_events.csv
CSV file containing timestamped click events generated by subjects interacting with zyBooks animations. Each event is associated with an ID denoting the animation, a caption describing the animation, a Boolean flag indicating whether the current animation has been completed, a string denoting the type of click event, and another Boolean flag indicating whether the '2x speed' option is active for the animation.

#### learning_question_events.csv
CSV file containing timestamped click events generated by subjects interacting with zyBooks learning questions. Each event is associated with an ID denoting the question set, a caption describing the question set, an integer denoting the question number within the set, and a Boolean flag indicating whether the current question has been correctly answered.

#### rating.csv
CSV file containing integer ratings on a 0 to 20 scale for each dimension of workload from the NASA Task Load Index (TLX), computed for each subject for each type of task based on NASA TLX survey results.
